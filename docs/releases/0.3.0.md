# Retrofetch v0.3.0

This release adds optional source-built native startup acceleration, compact v3
selection indexes, and safer activation/recovery while retaining Python playback.
It remains Linux/Kitty-only and preserves Fastfetch configuration and layout.

## Install and enable acceleration

Install Python 3.11+, Kitty/kitten, ImageMagick 7, and a Fastfetch build with Kitty
animation and ImageMagick support. Download the source archive and `SHA256SUMS`,
verify its SHA-256, then:

```sh
tar -xzf retrofetch-0.3.0.tar.gz
cd retrofetch-0.3.0
sh install.sh --accept-source-notices
```

Review the source notices before accepting. Default preparation downloads all
three collections (about 13.71 GB), requires substantial working space and can
take hours. Existing extracted sources can be reused with `--source`. Nothing
is downloaded or converted during terminal startup.

The normal installation is Python-only. Native acceleration is explicitly opt-in
and requires a C11 compiler plus OpenSSL headers/libcrypto; its build inputs are
included in the source distribution, not as prebuilt native wheels. Follow
[the native setup guide](../rendering.md#optional-v3native-acceleration), including
the managed package's explicit `PYTHONPATH`, `--refresh-runtime`, and
`--refresh-native` steps in the target Kitty terminal. Unsupported options,
Unicode query folding, ad-hoc filters, and stale profiles retain Python fallback.

## Changes and validation

- Compact v3 indexes accelerate playback while retaining complete index/catalog
  content verification and compatible v2/canonical fallback.
- Excessive JSON metadata nesting is rejected as invalid infrastructure rather
  than escaping selection fallback or overwriting an unrecognized index.
- Native activation stages publication/recovery beside each destination,
  including separate bin/lib filesystems; failed recovery retains diagnostic copies.
- Compiler/OpenSSL CI dependencies, native sanitizers and source-distribution
  build checks complement the Python regression and shell-guard suites.
- Actual isolated Kitty checks cover native combined left/right/top placement,
  animation-only playback, motion after exit, interactive prompt placement,
  scrolling/clearing and supported Python fallback.

A local 36,642-entry benchmark measured prepared named/filtered startup around
449 to 81 ms on the native path (about 82% faster). These are warm-cache process
startup/selection timings, not visible-first-frame or GIF-upload latency;
fallback paths do not promise native latency. Profiles bind exact geometry and
environment, so resizing can return playback to Python until explicitly refreshed.
No animation quality, timing, library coverage or user module configuration is
reduced for performance. The optional extra render cache remains disabled because
its supported read-only prerequisite was not met.

## Rights and release contents

Release assets are a code-only Python wheel, source archive and checksums.
The MIT license covers Retrofetch code, not the third-party animation collections.
Source notices and restrictions are retained; Internet Archive hosting and notice
acceptance do not grant additional rights. No animation assets are redistributed.
The wheel alone does not prepare the library. Shell startup remains opt-in, and
installation does not edit shell or Fastfetch configuration. No PyPI publication
or prebuilt cross-architecture native binary is part of this release.
