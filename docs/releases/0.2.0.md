# Retrofetch v0.2.0

Retrofetch displays retro animations beside your existing Fastfetch output in
Kitty on Linux. This release adds default acquisition of Essential Collection,
250K_ANIMATIONS, and all twelve Anime Factory discs, plus compatible upgrades.

## Install

Requires Python 3.11+, Kitty (`kitten`), ImageMagick 7 (`magick`), and Fastfetch
with Kitty animation and ImageMagick support. Install system dependencies first.
Download `retrofetch-0.2.0.tar.gz` and `SHA256SUMS` from this release; verify its
SHA-256 against the manifest, then:

```sh
tar -xzf retrofetch-0.2.0.tar.gz
cd retrofetch-0.2.0
sh install.sh --accept-source-notices
```

Read the source notices and installation guide before accepting them. Acceptance
acknowledges the notices; it does not grant rights to the third-party artwork.
Expect about 13.71 GB of downloads, substantial working space, and hours of
preparation. Interrupted installs preserve completed source caches for retry.
Use the same command to upgrade a managed installation. Shell startup remains
opt-in; no Fastfetch configuration is rewritten.

## Library and compatibility

The verified development build contains 36,642 usable catalog entries backed by
34,604 unique normalized GIFs. Existing selectors are preserved. New families use
collection-qualified identities; source aliases and notices remain available.
Incomplete payloads on the known damaged Anime Factory disc are excluded with
explicit diagnostics. Counts depend on the verified source identities and
conservative validation outcomes, not a promise that every source GIF is usable.

## Rights and assets

MIT covers Retrofetch code only. Third-party archives and animations are not
included in release assets; downloads originate from Internet Archive and retain
their own notices and restrictions. Review applicable terms before use or
redistribution. Hosting and successful download are not grants of permission.

Release assets are code-only wheel, source distribution, and SHA256SUMS. Installing
the wheel alone does not prepare the animation library; use the explicit source
installer above. Rendering remains Linux/Kitty only, without tmux/screen
passthrough. No PyPI publication is provided.
