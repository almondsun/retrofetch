# Prepared development data

This is the permanent location for Retrofetch's prepared development animation
library. The complete local import is hash-validated: 20,554 catalog entries
reference 20,284 unique GIFs. See [the import report](../docs/library-report.md).

- Future imports can use a staging directory or the configured collection download.
- Keep one selected usable variant per animation and preserve searchable aliases,
  provenance, source notices, and the import/exclusion manifest.
- Generated contents are ignored by Git; this README is documentation only.
- Do not move unvalidated files here and call the import complete.
- Verify the catalog and selected assets before requesting cleanup of `temp/`.
- Installed user assets live under XDG data home, not inside the Git checkout.

The initial disposable `temp/` staging was removed after verified allocation and
explicit user authorization. Generated assets and source caches are never committed.

See [the project brief](../docs/project.md) for selection rules and rights caveats.
